# Build LinkBase: A Curated Resource Directory

### Project Description

You are going to build LinkBase a clean directory where developers can discover the best tools and resources on the internet. First you will design a database that links specific resources to broader categories using Foreign Keys. Next you will learn how to build a dynamic filtering system so visitors can easily sort resources by topics like UI Design or Python. Then you will add a public form so anyone can suggest a cool new link. Finally you will customize the Django Admin dashboard so you can act as the gatekeeper easily reviewing and approving community submissions before they ever appear on the live site. You will write all of this using clear function based views to fully grasp how filtering and data management work under the hood.
